# Agent entry point

Read these files before changing the project:

1. [CLAUDE.md](CLAUDE.md): current architecture, invariants, and coding rules.
2. [ISSUES.md](ISSUES.md): open defects and reproduction commands.
3. [docs/QUEUE.md](docs/QUEUE.md): active work and completion criteria.
4. Relevant sections of [METHODOLOGY.md](METHODOLOGY.md) and
   [CONTEXT.md](CONTEXT.md).

For a dispatched task, also read
[docs/worker-brief.md](docs/worker-brief.md).

Files under `docs/briefs/`, `VERSION_HISTORY.md`, and `docs/adr/` are
historical evidence. Read one only when the active task cites it.

Keep project instructions in `CLAUDE.md).
